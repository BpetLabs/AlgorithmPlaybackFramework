# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0

### Added

- React controls and playback-state utilities for step-by-step algorithm
  visualizations.
- Array, stack, grid, graph, code, text, and playback-slider renderers.
- TypeScript declarations and ESM and CommonJS package builds.
- A public stylesheet and `--apf-*` theme variables.
- An Animated Playback starter with AI-assisted authoring prompts and a
  customizable page template.
